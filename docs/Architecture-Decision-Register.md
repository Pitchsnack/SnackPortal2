The Import edge is the sole exception: `ImportService` requires a `RoutedSessionProvider` implemented only by `database_router` and a `LineageEmitPort` implemented only by `lineage_service`; no service may supply both without importing another service. **(4) Factory authority.** `deployment.import_edge:create_app_from_env` is the **canonical native ASGI application factory for Edge 9** (`uvicorn deployment.import_edge:create_app_from_env --factory`). It takes no arguments, binds no socket, owns no address, and returns a composed `FastAPI` app and nothing else. **(5) Seam reuse, not re-derivation.** Every collaborator is built by the owning service's own published seam (`database_router.main.build_router_from_env`, `import_service.main.build_import_service_from_env`, `lineage_service.emit.LineageEmit`, `import_service.adapters.providers.http_import_api.create_app`); the root re-derives no wiring and parses no selector a service already parses, so there is exactly one composition architecture for Edge 9 and no second one. **(6) In-process residency.** A routed tenant session is a **live, transactional database handle bound to exactly one physical tenant database**; it MUST be constructed and consumed in-process and MUST NOT be serialized, proxied, or carried over HTTP or any other wire. **(7) Fail-closed startup.** A missing routing selector, missing directory-read selector, or malformed value raises **before anything is served**; there is no in-memory session-provider, lineage, or audit fallback. **(8) Composition-only scope.** The root contains no domain logic, no business rules, no SQL, no authorization policy, no tenant-selection policy, no lineage semantics, and no routing authority. **(9) Enforcement.** Direction is enforced by **two** import-linter `forbidden` contracts — one forbidding every service and `shared` from importing `deployment`, one forbidding `deployment` from importing the three un-authorized services — with `deployment` added to `root_packages`, plus an architecture guard under `backend/tests/architecture/`. **(10) Independence preserved.** `import_service ↛ database_router`, `import_service ↛ lineage_service`, `database_router ↛ import_service`, `lineage_service ↛ import_service`, and `services ↛ deployment` all remain in force; the existing service-independence contract is **not weakened, narrowed, or exempted** in any respect. **(11) No blanket future authority.** D-44 authorizes **this composition and no other**. Any additional cross-service `deployment` module, and any widening of the authorized import set, requires an **IC-012 amendment** naming the specific composition — and, where the change is materially architectural, an **ADR / register amendment** as well. Conformance to IC-012 is *not* sufficient authorization on its own.
- **Reason / Finding reference:** the Dan-authorized native FastAPI/Uvicorn all-9-edges startup migration required a native `--factory` startup path for every edge. Edge 9 (Import) could not obtain one inside `import_service` without either (a) `import_service` importing `database_router` and `lineage_service` — a direct violation of the service-independence contract — or (b) fetching a transactional session over HTTP, which is impossible for a live handle and would breach the Database-Router-only resolution rule.
